# Pdb

A personality-type social app (Expo / React Native, runs on iOS, Android and web) with a Supabase backend.

- App code: `artifacts/mobile/src` (see `docs/ARCHITECTURE.md` for the folder map)
- Backend schema: `supabase/migrations`
- Product overview, setup and screenshots: `README.md`
- Logo and design notes: `docs/BRANDING.md`

Other workspace packages: `artifacts/api-server` (a small Express stub) and `artifacts/mockup-sandbox` (a Vite component preview).
